# IT-2321 Lab 5: An Interactive Page: DOM, Events, and Timers

**Reading: Eloquent JavaScript, Chapters 14 and 15**

This lab is practice with responding to user events, changing the page through the DOM, and using a timer to drive live behavior.

## Getting started

1. Rename this repository to `it2321-lab05-lastname` (your last name, all lowercase) and set it to Private.
2. Clone it and open the folder in Visual Studio Code.
3. Open `index.html` in your browser, and open the developer console to see your output.
4. Write your code in `script.js`, replacing each `TODO` with your own work.

## What to do

- Respond to at least one user event with addEventListener.
- Change page content through the DOM (textContent, createElement, etc.).
- Change at least one style through the DOM.
- Use a timer (setInterval or setTimeout) for live behavior.
- Add one interactive feature of your own design.

## Files

- `index.html` — the page that loads your script. You usually do not need to change much here.
- `script.js` — where your work goes.
- `styles.css` — basic styling you may adjust.
